# 微信小程序调试排错清单

本项目在微信开发者工具里从「编译失败」到「跑起来」过程中实际踩过的坑，按出现顺序整理。
新环境复现项目时，照着这份清单逐条检查即可，不用重新 debug。

---

## 1. 启动前必做：项目配置

| 项 | 值 |
| --- | --- |
| AppID | `wxYOUR_APPID_HERE`（在 `miniprogram/project.config.json` 填写自己的 AppID） |
| 项目目录 | 选 `charging-radar/miniprogram`（**不要选外层 `charging-radar`**，否则报「找不到 app.json」） |
| 后端 | `server/mock_api.py`，默认监听 `http://localhost:3000`（本地开发用） |
| 启动方式 | 双击 `启动服务器.bat`（不要用 bash 的 `&` 后台，进程会被回收） |

启动后验证：

```bash
curl http://localhost:3000/health      # 注意是 /health，不是 /api/v1/health
```

## 2. 本地设置必须勾选「不校验合法域名」

**错误现象：**

```
GET http://localhost:3000 不在以下 request 合法域名列表中
[雷达扫描] 失败: request:fail url not in domain list
```

**解决：** 微信开发者工具 → 右上角「详情」→「本地设置」→ 勾选
**「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**。

> 说明：小程序正式环境强制 HTTPS + 域名白名单（mp 后台「开发管理 → 服务器域名」）。
> 开发期用 http://localhost 必须关掉校验，否则所有请求直接被拦截。

## 3. app.json 权限配置的雷区

### 3.1 `requiredPrivateInfos` 只接受 8 个合法值

```
chooseAddress / chooseLocation / choosePoi / getFuzzyLocation
getLocation / onLocationChange / startLocationUpdate / startLocationUpdateBackground
```

写 `openLocation` 会直接导致**模拟器启动失败**。

### 3.2 `getFuzzyLocation` 与 `getLocation` 互斥

两个同时写会报配置冲突，模拟器起不来。

### 3.3 本项目的做法：直接不用定位

`app.json` 里只保留：

```json
"permission": { "scope.userLocation": { "desc": "用于显示附近充电桩位置" } }
```

`app.js` 的 `getLocation()` 已改为**空实现 + 默认坐标**（深圳 22.5329, 113.9366），
真实定位代码保留注释。原因：

- 申请定位权限需要在 mp 后台提交用途说明，审核周期长
- 10 个演示站点全在深圳，真机定位到别的城市会查到 0 条结果

需要接真实定位时，取消注释并在 mp 后台申请 `getFuzzyLocation` 即可。

## 4. WXML 语法限制（编译期报错）

WXML 不是 JS，以下写法**全部不允许**：

| 错误写法 | 报错 | 正确写法 |
| --- | --- | --- |
| `{{order?.powerUsed}}` | `Bad value: unexpected token '.'` | `{{order.powerUsed \|\| 0}}` |
| `{{Math.random() * 100}}` | 不允许调用 JS 方法 | 在 JS 里算好放进 data |
| `wx:for="{{8}}"` | 数字不可靠，常渲染不出来 | JS 生成数组 `wx:for="{{portList}}"` |

**本项目已改造的页面：**

- `pages/charge/progress`：图表柱子改成 `chartBars` 数组 + `style="height: {{item}}%"`
- `pages/station/index`：端口网格 `portList`、评分星星 `starList`
- `pages/scan/index`：端口网格 `portList`

通用工具方法（各页 JS 内）：

```js
genPortList(n) {
  const arr = []
  for (let i = 1; i <= n; i++) arr.push(i)
  return arr
}
```

## 5. 前后端字段命名必须统一（camelCase）

后端 SQLite 查出来是 snake_case（`price_per_hour`、`total_ports`），
小程序 WXML 用的是 camelCase（`pricePerHour`、`totalPorts`），
不统一就会渲染成空白但**不报错**，最难排查。

**约定：所有接口出口一律 camelCase。**

已在 `server/mock_api.py` 统一的序列化：

- 站点：`stationCode / totalPorts / freePorts / occupiedPorts / faultPorts / pricePerHour / powerType / businessHours / distance`
- 订单：`orderNo / startTime / endTime / powerUsed / totalCost / station / stationBrand`
- 个人中心：`stats: { orderCount / totalPower / totalCost / carbonSaved }`

## 6. Python 后端源码不要写中文

`.py` 源文件里直接写中文字符串出现过两次 `SyntaxError`
（`invalid decimal literal` / `leading zeros in decimal integer literals`）。
原因是文件编码与解析器不一致。

**解决：中文数据抽到 `server/seed_stations.json`，用 `json.load()` 读取。**
同时电话号码 `400-888-0001` 这类必须加引号，否则被当成数字表达式。

## 7. 后台进程被回收

**现象：** bash 里 `python mock_api.py &` 启动后，工具调用一结束进程就没了，
再 curl 就是 502 / 「找不到指定的驱动器」。

**解决：**

1. 用 `启动服务器.bat` 双击启动（最省心）
2. 或在**同一次** bash 调用里用子 shell：`(python mock_api.py > server.log 2>&1 &)`
3. 端口 TIME_WAIT 占坑时换端口或等一会

---

## 8. SQLite 自增 ID 不连续

`DELETE FROM stations` 后 `AUTOINCREMENT` 不会从头开始，新插入的 ID 可能跳到 100+。
写测试脚本时用**动态取 ID**，别硬编码 `/stations/1`。

---

## 9. 离线兜底：UI 永不空白

即使上面第 2 步没勾选、或服务器没启动，雷达页也不会白屏。

- 数据文件：`miniprogram/utils/demo-data.js`（10 个深圳站点，ID 9001–9010）
- 触发位置：`pages/index/index.js` 的 `.catch()` 分支
- 页面表现：顶部出现黄色提示条「📴 离线演示模式（未连接服务器…）」

```js
}).catch(err => {
  app.hideLoading()
  console.warn('[雷达扫描] API 失败，切换离线演示数据:', err)
  const fallback = demo.queryDemoStations({ lat, lng, radius, sort })
  this.applyStations(fallback.stations, fallback.total, location, true)
})
```
